## 一、准备工作

### 1. 安装 1Panel

官网：[https://1panel.cn/](https://1panel.cn/)

CentOS：

```bash
curl -sSL https://resource.fit2cloud.com/1panel/package/quick_start.sh -o quick_start.sh && sh quick_start.sh
```

Ubuntu：

```bash
curl -sSL https://resource.fit2cloud.com/1panel/package/quick_start.sh -o quick_start.sh && sudo bash quick_start.sh
```

Debian：

```bash
curl -sSL https://resource.fit2cloud.com/1panel/package/quick_start.sh -o quick_start.sh && bash quick_start.sh
```

openEuler 或其他系统：

第一步，安装 Docker：

```bash
bash <(curl -sSL https://linuxmirrors.cn/docker.sh)
```

第二步，安装 1Panel：

```bash
curl -sSL https://resource.fit2cloud.com/1panel/package/quick_start.sh -o quick_start.sh && sh quick_start.sh
```

### 2. 安装青龙

进入 1Panel，点击“应用商店”，找到青龙并安装。

如果不使用 1Panel，则需要手动安装青龙。青龙官网：[whyour/qinglong](https://github.com/whyour/qinglong/tree/master)

### 3. Hosts 调试

> 此步骤用于解决国内服务器无法访问 GitHub 的问题。

项目：GitHub520  
官网：[https://gitee.com/klmahuaw/GitHub520](https://gitee.com/klmahuaw/GitHub520)

Hosts 文件位置：

```text
/etc/hosts
```

按照项目说明，将所需内容添加到该文件末尾。

## 二、安装脚本

BiliBiliToolPro 官网：[RayWangQvQ/BiliBiliToolPro](https://github.com/RayWangQvQ/BiliBiliToolPro)

进入青龙面板的配置文件页，将第 11 行：

```text
RepoFileExtensions="js py"
```

修改为：

```text
RepoFileExtensions="js py sh"
```

修改后，可选择以下任意一种拉库方式。

### 1. 使用订阅管理

- 名称：Bilibili
- 类型：公开仓库
- 链接：`https://github.com/RayWangQvQ/BiliBiliToolPro.git`
- 定时类型：crontab
- 定时规则：`2 2 28 * *`
- 白名单：`bili_task_.+\.sh`
- 文件后缀：`sh`

未提到的配置保持不变。保存后点击运行按钮，执行拉库。

### 2. 使用定时任务拉库

进入青龙面板的“定时任务”页，点击右上角“添加任务”，填写：

- 名称：拉取 Bili 库
- 命令：`ql repo https://github.com/RayWangQvQ/BiliBiliToolPro.git "bili_task_"`
- 定时规则：`2 2 28 * *`

保存后找到该定时任务，点击运行按钮。正常情况下，拉库成功后会自动添加 Bilibili 相关任务。第一次拉库可能失败，建议多尝试几次；如果始终失败，可改用另一种拉库方式。

## 三、登录与运行建议

在青龙定时任务中运行 `bili扫码登录` 任务，查看运行日志，并扫描日志中的二维码登录。

首次运行会自动安装 .NET 环境，耗时会比较长，之后不需要重复安装。也可以先运行 `bili-base` 安装 .NET。

- 建议禁用“批量取关主播”“尝试修复异常”和“尝试 CK”等任务。
- 安装和登录完成后，建议禁用登录和 base 任务，但不要删除。
- 不建议使用 `ghproxy.com` 加速，可能出现 SSL 错误；无法访问 GitHub 时可使用 GitHub520。
- 不建议使用作者给出的命令手动安装 .NET，添加 PATH 时可能报错；建议使用 `bili_base` 安装。
- .NET 安装通常需要 30 分钟以上，请耐心等待。
