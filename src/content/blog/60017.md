## 前言

对于低配置服务器，使用 ICQQ + Miao-Yunzai 可能遇到风控、封号和 QSign 服务问题；使用 QQNT + LiteLoaderQQNT + LLOneBot 搭建 TRSS-Yunzai，又可能出现资源占用较高、机器人不稳定的问题。因此，可以使用 NapCat 作为协议端。

推荐配置：2 核 2 GB。1 核 1 GB 的服务器更适合使用 ICQQ。

> 本教程仅供学习与交流，禁止用于违法用途。使用 NapCat 搭建 TRSS-Yunzai 机器人仍然存在封号风险；如果不希望账号被冻结，请勿继续操作。

## 什么是 NapCat

NapCatQQ（猫猫框架）是现代化的、基于 NTQQ 的 Bot 协议端实现。

NapCat 具有以下特点：

- **高性能**：可承载大量群聊和多线程消息发送。
- **多种启动方式**：支持无头、LiteLoader 插件和 QQ GUI 三种方式。
- **多平台支持**：覆盖 Windows、Linux（可选 Docker）、Android Termux 和 macOS。
- **安装简单**：支持一键脚本、程序自动部署和镜像部署等方式。
- **低占用**：无头模式资源占用较低，适合服务器运行。
- **接口丰富**：实现大部分 OneBot 和 go-cqhttp 接口，并提供扩展 API。
- **WebUI**：自带 WebUI，方便远程管理。
- **维护活跃**：能够较快适配新版本。

总结来说，NapCat 是一个无头运行的 QQNT 协议端，并自带 OneBot 连接能力，资源占用较少，适合搭建 QQ 机器人。

- [NapCatQQ GitHub 仓库](https://raincliff.top/link.php?a=aHR0cHM6Ly9naXRodWIuY29tL05hcE5la28vTmFwQ2F0UVE=)
- [NapCatQQ 官方文档](https://raincliff.top/link.php?a=aHR0cHM6Ly9uYXBuZWtvLmdpdGh1Yi5pby96aC1DTi8=)

## 开始安装

### 连接服务器

使用 SSH 客户端连接服务器。如果使用 Windows 10 或 Windows 11，也可以直接使用系统自带的 OpenSSH。

打开 CMD，输入：

```bash
ssh root@Your-Server-IP
```

将 `Your-Server-IP` 替换为服务器 IP。如果不是 root 用户，请把 `root` 换成自己的用户名；如果 SSH 端口不是 22，可使用 `ssh -p 端口 用户名@服务器IP`。

首次连接出现主机指纹确认提示时，确认地址无误后输入 `yes`。

### 安装 NapCat

NapCat 提供多种安装方式：LiteLoaderQQNT、无头 Shell 和 QQ GUI。方法 1 和 3 属于有头启动，应使用 Framework 版本；方法 2 属于无头启动，应使用 Shell 版本。这里建议使用无头方式，资源占用更低。

使用一键脚本安装：

```bash
curl -o napcat.sh https://nclatest.znin.net/NapNeko/NapCat-Installer/main/script/install.sh && sudo bash napcat.sh
```

如果安装过程中询问是否使用 Docker，可根据实际需要选择；不使用 Docker 时输入 `n`。NapCat 会自动安装 Linux QQ。

常用命令：

```bash
# 前台启动
xvfb-run -a qq --no-sandbox

# 后台启动，需要扫码登录
screen -dmS napcat bash -c "xvfb-run -a qq --no-sandbox"

# 后台快速登录，无需再次扫码
screen -dmS napcat bash -c "xvfb-run -a qq --no-sandbox -q QQ号码"

# 查看日志
screen -r napcat
```

第一次登录建议先使用扫码方式。扫码成功后，下次可以使用带 `-q QQ号码` 的命令快速登录。

### 安装 TRSS-Yunzai

[TRSS-Yunzai 官方 Gitee 仓库](https://raincliff.top/link.php?a=aHR0cHM6Ly9naXRlZS5jb20vVGltZVJhaW5TdGFyU2t5L1l1bnphaQ==)

先安装 Redis。Ubuntu 示例：

```bash
apt install redis-server
redis-cli --version
```

其他系统请根据发行版选择相应安装方式。

接下来使用 NVM 安装 Node.js：

```bash
# 安装 NVM
bash -c "$(curl -fsSL https://gitee.com/RubyMetric/nvm-cn/raw/main/install.sh)"

# 列出可安装版本
nvm ls-remote

# 安装 Node.js 22.9.0
nvm install v22.9.0
```

也可以使用 `nvm install v版本号` 安装其他版本，并通过 `nvm use 版本号` 切换。安装 NVM 后需要重新打开终端，无需重启服务器。

克隆 TRSS-Yunzai：

```bash
# 国外服务器可使用 GitHub
git clone --depth 1 https://github.com/TimeRainStarSky/Yunzai

# 国内服务器可使用 Gitee
git clone --depth 1 https://gitee.com/TimeRainStarSky/Yunzai

cd Yunzai
```

安装 pnpm 和项目依赖：

```bash
npm i -g pnpm
pnpm i
```

至此，基础环境和程序安装完成。后续连接与机器人配置请结合 NapCat 和 TRSS-Yunzai 的最新文档进行设置。
