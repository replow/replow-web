## 域名的选购

对于一个网站来说，首先需要确定域名。可以先想好网站的名字，再按照名字选购域名。

想寻找便宜的域名，可以使用：[哪煮米——全网域名一站比价](https://www.nazhumi.com/)

这里给出一些常见域名的最低价注册商参考：

- `.com`：Porkbun，54.5 RMB
- `.xyz`：Porkbun，11 RMB
- `.cn`：华为云，25 RMB
- `.net`：NameSilo，25.37 RMB（DreamHost 更便宜，但不能使用支付宝）
- `.co`：Porkbun，21 RMB
- `.top`：Spaceship，7.6 RMB

选择域名注册商和域名后缀时，还需要考虑自己的业务。如果后续准备备案，建议选择阿里云、腾讯云等国内厂商，办理备案会更方便。

## 更换 Nameserver

对于在国外域名注册商注册的域名，可以将 DNS 解析更换为国内 DNS 服务商，例如阿里云 DNS 或 DNSPod，日常解析管理会更方便。

下面以在 NameSilo 注册的域名为例。

进入后台，选择“Domain Manager”：

![NameSilo 后台的 Domain Manager 入口](https://cdn.replow.org/article/2026/08/88129f8b88c3ae4423e0f59253aef87c67960717.png)

点击需要更改 NS 的域名：

![在 NameSilo 中选择需要修改的域名](https://cdn.replow.org/article/2026/08/34e84a5d887d1a75d4c442e64c2210f10125e193.png)

在域名详情页找到 Nameservers：

![NameSilo 域名详情中的 Nameservers 设置](https://cdn.replow.org/article/2026/08/11db8a52ee5ef1465bcbef030574e169cdc510b6.png)

点击修改，然后打开[阿里云 DNS 解析控制台](https://dns.console.aliyun.com/)，点击“添加域名”：

![阿里云 DNS 控制台的添加域名页面](https://cdn.replow.org/article/2026/08/30d38021a6ee06ab3ef75e2dee69f1060d39326b.png)

输入自己的域名。添加完成后，阿里云会提供 Nameserver 地址；回到域名注册商的 Nameserver 修改页面，删除原来的 Nameserver，再填入新的地址。

修改完成后，就可以在新的 DNS 服务商中管理域名解析记录：

![阿里云 DNS 控制台的域名解析记录页面](https://cdn.replow.org/article/2026/08/c73d959d7858335647985cb2142e839ba5114d94.png)
