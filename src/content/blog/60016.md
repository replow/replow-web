## 服务器的选购

如果网站没有备案，通常只能选择中国大陆以外地区的服务器；完成备案后，也可以选择中国大陆地区的服务器。

服务器推荐：[UCloud 云服务器](https://www.ucloud.cn/site/active/kuaijiesale.html)

![UCloud 云服务器活动与价格页面](https://cdn.replow.org/article/2026/08/a8b2caa745c05b24cb456dbc91abc297359dbc11.png)

国内服务器最低约 59 元/年，港台服务器最低约 83 元/年（2 核 2 GB）。国外服务器地区推荐香港、新加坡，也可以选择美国的大带宽服务器。

服务器系统建议选择 Ubuntu。CentOS 已停止常规维护，使用时可能需要更换软件源。建站通常不建议选择 Windows，除非服务器配置较高或业务有明确需要。

## 安装管理面板

购买服务器后，使用 SSH 连接服务器，再安装服务器管理面板。目前国内常用的面板有宝塔和 1Panel。

- [宝塔面板](https://www.bt.cn/)
- [1Panel](https://1panel.cn/)

追求传统环境和稳定性可以选择宝塔；1Panel 基于 Docker，使用和部署方式有所不同。

### 安装 1Panel

CentOS：

```bash
curl -sSL https://resource.fit2cloud.com/1panel/package/quick_start.sh -o quick_start.sh && sh quick_start.sh
```

Ubuntu：

```bash
curl -sSL https://resource.fit2cloud.com/1panel/package/quick_start.sh -o quick_start.sh && sudo bash quick_start.sh
```

Debian：

```bash
curl -sSL https://resource.fit2cloud.com/1panel/package/quick_start.sh -o quick_start.sh && bash quick_start.sh
```

### 安装宝塔

CentOS：

```bash
url=https://download.bt.cn/install/install_lts.sh; if [ -f /usr/bin/curl ]; then curl -sSO $url; else wget -O install_lts.sh $url; fi; bash install_lts.sh ed8484bec
```

Debian：

```bash
wget -O install.sh https://download.bt.cn/install/install_lts.sh && bash install.sh ed8484bec
```

Ubuntu：

```bash
wget -O install.sh https://download.bt.cn/install/install_lts.sh && sudo bash install.sh ed8484bec
```

其他系统请前往对应面板官网查看最新安装说明。
