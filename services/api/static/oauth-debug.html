Replow OAuth 2.1

标准 授权码 + PKCE 流程调试台

这是一个真实可跑的 OAuth 客户端。它会在浏览器里生成 PKCE 参数、引导你完成授权、把授权码换成 token，再用 token 读取 /oauth/userinfo。所有请求都打到线上 account.example.com，没有 mock。

GET /oauth/authorize POST /oauth/token GET /oauth/userinfo POST /oauth/introspect POST /oauth/revoke GET /oauth/.well-known/oauth-authorization-server

1 客户端配置

已预填一个回环地址测试客户端，可直接使用。

注册客户端需要 access_token。请在下方「获取 access_token」里用账号密码换取， 或点「用当前登录状态」直接复用 SSO 会话 —— 两种方式都会写入这里的输入框。
OAuth 已迁到 account.example.com/oauth：本页与 cookie replow_sso 同处 .example.com 注册域， 所以 POST /v1/auth/session 能直接换到令牌，无需再次登录。

2 流程进度

每一步的实际请求与响应都会记录在下方。

  1. 生成 PKCE code_verifier / code_challenge（S256）
  2. 跳转授权端点，携带 client_id 与 challenge
  3. 用户同意，回调拿到 authorization_code 与 state
  4. 用 code + verifier 换取 access_token / refresh_token
  5. 用 access_token 调用 /oauth/userinfo

5 原始 HTTP 轨迹

完整请求与响应，便于排查对接问题。

—
  • 授权码是一次性的：同一个 code 换第二次会被拒绝（invalid_grant）。
  • PKCE 校验码不匹配会被拒绝（pkce_verification_failed）。
  • refresh_token 每次使用都会轮换，旧的立即失效。
  • 未知 scope 会在授权入口就被拦下（invalid_scope）。
